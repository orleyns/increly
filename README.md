# incr&ly

A simple and open-source event counter for iOS.

## Concept

Incr&ly lets you create as many customizable counters as you want. Every tap records a timestamped event, making it possible to track both a total and the time elapsed since the latest occurrence.

Examples: ☕ Coffee, 🍬 Candies, 🎸 Training, 💡 Habits.

## Planned features

- Unlimited customizable counters
- Custom name, emoji and color
- Optional initial value
- Timestamped events
- Time since last occurrence
- Detailed history and calendar
- Statistics and intervals
- Interactive Home Screen widgets
- Local-first storage
- No account, ads or backend in V1

## Technology

- Swift
- SwiftUI
- SwiftData
- WidgetKit
- App Intents

The interface will follow a modern iOS visual language, including Liquid Glass where appropriate.

## Project status

Early development — V1 specification and architecture are being established.
